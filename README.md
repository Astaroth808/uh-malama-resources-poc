# UH Mālama Resources — Proof of Concept

A single-file, interactive proof-of-concept dashboard for a university resource planning and budgeting platform, prepared in connection with RFP No. 27-6284.

> **Not an official University of Hawaiʻi site.** This is a vendor proof of concept. All figures, positions, requests and integration statuses are simulated for demonstration only.

## What it shows

- **Executive Dashboard** — systemwide KPIs, revenue by source, budget by campus, six-year outlook
- **Budget Explorer** — System → Campus → College → Department hierarchy with roll-up and drill-down
- **Scenario Modeling** — what-if sliders for enrollment, tuition, state funding, fringe and cost growth
- **Labor Planning** — sample position roster with salary and fringe calculations
- **Workflow Queue** — sample budget requests moving through campus and system review
- **Integration Status** — conceptual KFS and PeopleSoft connections and technical compliance notes

## Run it

Open `index.html` in a browser. Charts load Plotly from its CDN, so an internet connection is needed for them to render. A light/dark theme toggle is in the top bar.
